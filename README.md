## Για τους μαθητές

Κάθε κεφάλαιο έχει θεωρία, παραδείγματα, εργαστήριο και quiz. Στον χάρτη μαθημάτων φαίνεται ποια κεφάλαια έχουμε δουλέψει και ποια ακολουθούν. Η προσωπική μελέτη καταγράφεται ξεχωριστά στην «Πρόοδό μου».

Στο **Γράψε Python** μπορείς να γράψεις και να τρέξεις προγράμματα χωρίς εγκατάσταση ή λογαριασμό. Το «Δοκίμασέ το» κάτω από τα παραδείγματα ανοίγει τον κώδικα στο εργαστήριο. Οι ασκήσεις έχουν δικό τους πρόχειρο, ώστε να συνεχίζεις από εκεί που σταμάτησες.

- **Εκτέλεση:** τρέχει ολόκληρο το πρόγραμμα από την αρχή. Οι μεταβλητές της προηγούμενης εκτέλεσης δεν διατηρούνται.
- **input():** συμπλήρωσε πρώτα τα «Δεδομένα εισόδου», μία απάντηση ανά γραμμή. Δεν υπάρχει ακόμη ζωντανή πληκτρολόγηση απαντήσεων κατά την εκτέλεση.
- **Διακοπή:** σταματά ένα πρόγραμμα που αργεί ή επαναλαμβάνεται χωρίς τέλος.
- **Όνομα προγράμματος:** λατινικά γράμματα, αριθμοί και underscore (`_`), με γράμμα ή `_` στην αρχή, π.χ. `my_program_1`. Οι δεσμευμένες λέξεις της Python δεν χρησιμοποιούνται ως ονόματα. Τα μη έγκυρα ονόματα προσαρμόζονται αυτόματα, και στα εισαγόμενα αρχεία.
- **Αποθήκευση προγράμματος:** κρατά τον κώδικα με όνομα στα «Προγράμματά μου». Οι αλλαγές αποθηκεύονται αυτόματα.
- **Λήψη / Άνοιγμα .py:** μεταφέρεις τη δουλειά σου σε άλλον υπολογιστή ή τη συνεχίζεις στο IDLE. Το άνοιγμα αρχείου δημιουργεί ξεχωριστό πρόγραμμα.
- **Πληκτρολόγιο:** Ctrl/⌘ + Enter για εκτέλεση, Tab για τέσσερα κενά. Με Esc και έπειτα Tab φεύγεις από τον editor.

Τα προγράμματα και η πρόοδος αποθηκεύονται **στον συγκεκριμένο browser**, χωρίς συγχρονισμό μεταξύ συσκευών ή αποστολή στον εκπαιδευτή. Η διαγραφή δεδομένων του browser τα διαγράφει. Κατέβαζε ένα .py για τις εργασίες που θέλεις να κρατήσεις. Σε ιδιωτική περιήγηση η αποθήκευση μπορεί να είναι προσωρινή. Η επαναφορά προόδου δεν διαγράφει τα προγράμματα.

## Υλικό και σειρά μαθημάτων

Το μάθημα βασίζεται στην παρουσίαση `slides_python.pptx` (344 διαφάνειες). Κάθε ενότητα αναφέρει τις σχετικές διαφάνειες. Οι επιπλέον ασκήσεις σημειώνονται ως πρωτότυπες. Τα quiz προορίζονται για εξάσκηση, όχι ως επίσημες ερωτήσεις πιστοποίησης.

1. Εισαγωγή, print/input, τύποι και μετατροπές, μεταβλητές, strings και τελεστές.
2. Συνθήκες, επαναλήψεις, συστήματα αρίθμησης και bits.
3. Λίστες, πίνακες, strings, tuples και dictionaries.
4. Συναρτήσεις, scope, αναδρομή, exceptions και παιχνίδια επανάληψης.

Οι πηγές και οι σύνδεσμοι στην τεκμηρίωση της Python βρίσκονται και μέσα στην ιστοσελίδα.

## Αλλαγή τρέχοντος μαθήματος

Άνοιξε το `curriculum.js`. Κάθε κεφάλαιο έχει ένα πεδίο `status`:

| Τιμή | Ένδειξη |
| --- | --- |
| `taught` | Έχει διδαχθεί |
| `next` | Επόμενο μάθημα |
| `soon` | Προσεχώς |

Όταν ολοκληρώνουμε ένα μάθημα, αλλάζουμε το `next` σε `taught` και βάζουμε `next` στο επόμενο. Κράτα μόνο ένα κεφάλαιο με `next`. Η αρχική σελίδα, οι μετρητές, το μενού και ο χάρτης ενημερώνονται από αυτές τις τιμές.

Στο ίδιο αρχείο αλλάζουμε θεωρία, παραδείγματα, εργαστήρια και quiz. Τα `id` των κεφαλαίων καλό είναι να μένουν σταθερά, επειδή συνδέονται με την αποθηκευμένη πρόοδο. Τα πρόχειρα ασκήσεων χρησιμοποιούν το `id` του κεφαλαίου και τη θέση της άσκησης· η αλλαγή σειράς των ασκήσεων χρειάζεται προσοχή.

## Τοπική δοκιμή

Από τον φάκελο της ιστοσελίδας, με εγκατεστημένη Python:

```sh
python -m http.server 8000
```

Άνοιξε `http://localhost:8000`. Το εργαστήριο χρειάζεται HTTP/HTTPS και δεν λειτουργεί με διπλό κλικ στο `index.html` (`file://`). Δεν χρειάζεται διαδικασία build.

## Πώς λειτουργεί η Python

Χρησιμοποιούμε το δωρεάν, ανοικτού κώδικα [Pyodide 0.29.2](https://pyodide.org/en/0.29.2/), που κατεβαίνει από το jsDelivr όταν πατηθεί Εκτέλεση. Δεν απαιτείται API key, συνδρομή ή server εκτέλεσης κώδικα. Η εφαρμογή δεν ανεβάζει τα προγράμματα σε υπηρεσία εκτέλεσης ή αποθήκευσης. Ο κώδικας που γράφει ο μαθητής εκτελείται τοπικά και μπορεί να χρησιμοποιεί τις δυνατότητες δικτύου του browser.

Κάθε εκτέλεση ξεκινά νέο Web Worker και καθαρό περιβάλλον Python. Η διακοπή τερματίζει τον Worker, οπότε δεν μπλοκάρει η πλοήγηση. Όρια: 60 δευτερόλεπτα για φόρτωση, 30 δευτερόλεπτα εκτέλεσης, 65.536 χαρακτήρες εξόδου και αρχείο εισαγωγής έως 100 KB. Μετά από νέο φόρτωμα σελίδας τα αποτελέσματα εκτέλεσης δεν διατηρούνται, αλλά ο κώδικας και οι απαντήσεις εισόδου διατηρούνται.

Τα προγράμματα αποθηκεύονται σε IndexedDB (`robotonio-python-workbench-v1`), με προσωρινή καταγραφή αλλαγών στο localStorage. Η προσωπική πρόοδος χρησιμοποιεί το ξεχωριστό κλειδί `robotonio-pcep-saturday-v1`.

Υποστηρίζονται οι ασκήσεις κονσόλας του μαθήματος και η διαθέσιμη standard library του Pyodide. Δεν υπάρχουν tkinter, εγκατάσταση πακέτων με pip, μόνιμο Python filesystem, λογαριασμοί μαθητών ή πίνακας εκπαιδευτή. Το αρχικό κατέβασμα χρειάζεται σύνδεση· η offline λειτουργία δεν είναι εγγυημένη. Το περιβάλλον δεν προορίζεται ως απομονωμένος χώρος για εκτέλεση άγνωστου, μη έμπιστου κώδικα.
