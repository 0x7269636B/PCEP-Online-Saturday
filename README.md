# ROBOTONIO · Python PCEP · Τμήμα Σαββάτου

Ελληνικό εκπαιδευτικό site για **Σάββατο 14:00–15:30**, έτοιμο για GitHub Pages. Δεν δηλώνει τοποθεσία, ημερομηνίες μαθημάτων ή εξέτασης.

Προτεινόμενο **νέο** αποθετήριο: `ROBOTONIO-Lab/pcep-saturday-1430`. Το όνομα είναι πρόταση· δεν έχει δεσμευτεί ή δημιουργηθεί. Μην αντικαταστήσετε το υπάρχον `pcep-2026-kor`.

## Περιεχόμενα

- 18 κεφάλαια με στόχους, θεωρία, 65 αποσπάσματα Python και αναφορές στις διαφάνειες.
- 8 διδαγμένες ενότητες: εισαγωγή, print/input, types/casting, μεταβλητές, strings +/*, αριθμητικοί, συγκριτικοί και λογικοί τελεστές.
- Επόμενο μάθημα: **if / elif / else**, σαφώς μη διδαγμένο.
- 9 επόμενα κεφάλαια, όλα με σήμανση **Προσεχώς**. Είναι διαθέσιμα για προεπισκόπηση, όχι ημερολογιακά κλειδωμένα.
- 19 εργαστήρια με βήματα και ενδεικτικές λύσεις, 31 ερωτήσεις αυτοελέγχου.
- 6 διαδραστικές προσομοιώσεις: input/echo, υποτείνουσα, πλαίσιο ASCII, λογικές συνθήκες, αφαίρεση φωνηέντων, πέτρα–ψαλίδι–χαρτί.
- Φάκελος `examples/` με 19 έτοιμα αρχεία Python των ενδεικτικών λύσεων.
- Αναζήτηση, φίλτρα, responsive sidebar, αντιγραφή κώδικα, εκτυπώσιμο cheatsheet.
- Προσωπική πρόοδος σε localStorage. Δεν υπάρχει backend ή πίνακας εκπαιδευτή.
