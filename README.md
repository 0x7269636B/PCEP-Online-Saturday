# ROBOTONIO · Python PCEP · Τμήμα Σαββάτου

Ελληνικό εκπαιδευτικό site για **Σάββατο 14:00–15:30**, έτοιμο για GitHub Pages. Δεν δηλώνει τοποθεσία, ημερομηνίες μαθημάτων ή εξέτασης.

Προτεινόμενο **νέο** αποθετήριο: `ROBOTONIO-Lab/pcep-saturday-1430`. Το όνομα είναι πρόταση· δεν έχει δεσμευτεί ή δημιουργηθεί. Μην αντικαταστήσετε το υπάρχον `pcep-2026-kor`.

## Περιεχόμενα

- 18 κεφάλαια με στόχους, θεωρία, 65 αποσπάσματα Python και αναφορές στις διαφάνειες.
- 8 διδαγμένες ενότητες: εισαγωγή, print/input, types/casting, μεταβλητές, strings +/*, αριθμητικοί, συγκριτικοί και λογικοί τελεστές.
- Επόμενο μάθημα: **if / elif / else**, σαφώς μη διδαγμένο.
- 9 επόμενα κεφάλαια, όλα με σήμανση **Προσεχώς**. Είναι διαθέσιμα για προεπισκόπηση, όχι ημερολογιακά κλειδωμένα.
- 19 εργαστήρια με βήματα και ενδεικτικές λύσεις, 31 ερωτήσεις αυτοελέγχου.
- 6 διαδραστικές προσομοιώσεις: input/echo, υποτείνουσα, πλαίσιο ASCII, λογικές συνθήκες, αφαίρεση φωνηέντων, πέτρα–ψαλίδι–χαρτί.
- Φάκελος `examples/` με 19 έτοιμα αρχεία Python των ενδεικτικών λύσεων.
- Αναζήτηση, φίλτρα, responsive sidebar, αντιγραφή κώδικα, εκτυπώσιμο cheatsheet.
- Προσωπική πρόοδος σε localStorage. Δεν υπάρχει backend ή πίνακας εκπαιδευτή.

## Άμεσο άνοιγμα

Αποσυμπιέστε ολόκληρο το project και ανοίξτε το `index.html` στον browser. Δεν χρειάζεται εγκατάσταση πακέτων ή build. Κρατήστε τα `app.js`, `curriculum.js`, `styles.css` και `favicon.svg` δίπλα στο HTML.

Για πλήρη τοπική συμπεριφορά clipboard και αποθήκευσης, προτιμήστε έναν απλό τοπικό server:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Ανοίξτε `http://127.0.0.1:8000/`. Σταματήστε τον server με Ctrl+C. Στο άμεσο άνοιγμα ως αρχείο, αν δεν επιτρέπεται πρόσβαση στο clipboard, η λειτουργία αντιγραφής επιλέγει τον κώδικα για Ctrl+C / ⌘C. Η συμπεριφορά localStorage σε file URLs εξαρτάται από τον browser.

## Δημοσίευση στο GitHub Pages — χωρίς εργαλεία ανάπτυξης

1. Συνδεθείτε στο GitHub με λογαριασμό που μπορεί να δημιουργήσει αποθετήριο στον οργανισμό **ROBOTONIO-Lab**.
2. Επιλέξτε **New repository**, owner `ROBOTONIO-Lab`, όνομα `pcep-saturday-1430` (ή άλλο ξεχωριστό διαθέσιμο όνομα) και **Public**.
3. Από **Add file → Upload files**, ανεβάστε τα **περιεχόμενα** αυτού του φακέλου στη ρίζα του νέου αποθετηρίου. Το `index.html` πρέπει να βρίσκεται απευθείας στη ρίζα, όχι μέσα σε δεύτερο φάκελο `pcep-saturday`.
4. Κάντε commit στο `main`. Αν ανεβάζετε από το web και δεν εμφανίζεται το κρυφό `.nojekyll`, δημιουργήστε ένα άδειο αρχείο με αυτό το όνομα μέσω **Add file → Create new file**. Το site δεν χρειάζεται Jekyll.
5. **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
6. Επιλέξτε branch **main**, folder **/(root)** και **Save**.
7. Περιμένετε να ολοκληρωθεί η δημοσίευση. Η σελίδα **Settings → Pages** εμφανίζει το πραγματικό live URL. Με το προτεινόμενο όνομα, το αναμενόμενο URL είναι `https://robotonio-lab.github.io/pcep-saturday-1430/` — **δεν είναι ήδη δημοσιευμένο**.
8. Ελέγξτε αρχική, quiz, αντιγραφή κώδικα και πλοήγηση από κινητό.

Η ρύθμιση της πηγής Pages απαιτεί δικαιώματα admin ή maintainer στο repository. Οι δημόσιες σελίδες υποστηρίζονται από δημόσια repositories στο GitHub Free· ισχύουν επίσης οι πολιτικές του οργανισμού. [Επίσημες οδηγίες GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Δεν χρειάζεται προσαρμοσμένο GitHub Actions workflow. Οι διαδρομές αρχείων είναι σχετικές και η πλοήγηση χρησιμοποιεί hash links, οπότε λειτουργεί και κάτω από υποφάκελο repository χωρίς επιπλέον ρύθμιση βάσης.

Προσαρμόστε το remote στο πραγματικό νέο repo και ενεργοποιήστε Pages όπως παραπάνω. Δεν περιλαμβάνονται tokens ή στοιχεία σύνδεσης.

## Αλλαγές ύλης και προόδου τάξης

Το `curriculum.js` περιέχει όλο το εκπαιδευτικό περιεχόμενο. Κάθε κεφάλαιο έχει:

```js
{
  id: 'if',
  title: 'if, elif & else',
  status: 'next', // taught | next | soon
  slides: '94–111',
  sections: [],
  labs: [],
  quiz: []
}
```

- Μετά τη διδασκαλία της if, αλλάξτε το `status` της σε `taught` και του επόμενου κεφαλαίου σε `next`.
- Ενημερώστε επίσης τα στοιχεία της αρχικής στη `home()` του `app.js`: αριθμό διδαγμένων ενοτήτων, κάρτα επόμενου μαθήματος και κείμενο της αρχικής. Η τρέχουσα αρχική είναι επιμελημένη ειδικά για το σημείο πριν από την if.
- Τα `icon` είναι αριθμοί κεφαλαίων, όχι ημερομηνίες ή αύξοντες αριθμοί συναντήσεων. Οι χρόνοι είναι εκτιμήσεις προσωπικής μελέτης, όχι το ωρολόγιο πρόγραμμα της τάξης.
- Οι συναρτήσεις `S`, `L`, `Q` στην αρχή του αρχείου δημιουργούν ενότητες θεωρίας, labs και ερωτήσεις. Το `answer` στο quiz είναι δείκτης που ξεκινά από **0**.
- Διατηρήστε τα `id` σταθερά, ώστε να λειτουργούν οι παλιοί σύνδεσμοι και η αποθηκευμένη πρόοδος.
- Οι ενδεικτικές λύσεις προορίζονται για Python 3. Οι φόρμες του browser προσομοιώνουν συγκεκριμένα παραδείγματα με JavaScript. Δεν υπάρχει γενική εκτέλεση Python ή υποβολή εργασιών.

## Πηγές και πιστότητα

Η παρουσίαση `slides_python.pptx` με **344 διαφάνειες** ανακτήθηκε από τη συνδεδεμένη προηγούμενη συνομιλία και αναλύθηκε. Τα εργαστήρια 27, 81 και 82 αξιοποίησαν και τις εικόνες των πραγματικών αναμενόμενων εξόδων. Δεν ενσωματώνεται ολόκληρο το αρχείο PPTX στο δημόσιο project.

Δείτε το `CONTENT_MAP.md` για την αντιστοίχιση ενοτήτων–διαφανειών και τη σελίδα **Πηγές & σημειώσεις** για τις τεχνικές διορθώσεις. Η εκπαιδευτική προσαρμογή **δεν αποτελεί πλήρη μεταγραφή κάθε διαφάνειας ούτε επίσημο πλήρες syllabus ή mock examination της πιστοποίησης PCEP**. Η βασική συνέχεια οργανώθηκε από την παρουσίαση και τον [χάρτη αναφοράς](https://robotonio-lab.github.io/pcep-2026-kor/). Τα generators και οι ειδικές δραστηριότητες/εξετάσεις του άλλου τμήματος δεν υιοθετήθηκαν ως υποχρεωτική ύλη.

Τα καινούρια βήματα, οι λύσεις, τα quiz και οι επεκτάσεις δηλώνονται ως πρωτότυπα ή προσαρμογές. Δεν αποδίδεται νέα άδεια χρήσης στο προϋπάρχον εκπαιδευτικό υλικό ή στην επωνυμία ROBOTONIO.

## Τεχνικά χαρακτηριστικά

- Απλό HTML / CSS / JavaScript, χωρίς npm, CDN, εξωτερικές γραμματοσειρές ή runtime εξαρτήσεις.
- Τοπικός χρωματισμός σύνταξης με escaping HTML. Δεν χρησιμοποιείται eval για κώδικα χρήστη.
- Η πρόοδος αποθηκεύεται με το κλειδί `robotonio-pcep-saturday-v1`. Η ολοκλήρωση απαιτεί δήλωση μελέτης και lab, μαζί με πλήρες quiz. Μπορεί να μηδενιστεί από τη σχετική σελίδα.
- Αλλαγή browser, συσκευής ή διεύθυνσης φιλοξενίας δεν μεταφέρει την πρόοδο. Ιδιωτική περιήγηση ή αποκλεισμένη αποθήκευση μπορεί να την καταστήσει προσωρινή.
- Απαντήσεις quiz υπάρχουν στον πηγαίο κώδικα, αφού είναι εργαλείο αυτοελέγχου και όχι ασφαλής εξεταστική πλατφόρμα.
- Responsive διατάξεις και μενού για κινητά, ορατή εστίαση πληκτρολογίου, labels στις φόρμες, feedback με live regions, εκτύπωση cheatsheet.
